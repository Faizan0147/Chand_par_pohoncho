# M4 — Shaded-relief map and permanently-shadowed-region (PSR) layer (OPTIONAL)
Read `AGENT.md` first. **People:** 2. This module adds features the team wanted to limit: it is the **first thing to cut** if time runs short. The map must ship alone if the PSR overlay slips.

**Split:** M4a map image + click-to-open; M4b PSR overlay.
**Owns:** new `src/components/SiteMap.jsx`, new scripts `pipeline/make_map.py`, `pipeline/make_psr.py`, new data files `public/data/map.*`, `public/data/psr.json`, the map section of `Pick.jsx`. **Must not edit:** `Site.jsx`, `sites.json` (new data goes in new files).

## Steps
1. **M4a:** render a shaded-relief image of the south polar region from a LOLA DEM (can reuse mosaic window reads; see AGENT.md section 5; keep the image small, e.g. <= 1 MB, for phones). SVG overlay of the 7 sites in polar-stereographic coordinates (same CRS as the DEM; **not** plain lat/lon); click a marker -> `#/site/<id>` preserving URL params via `useKeepSearch`.
2. **M4b:** PSR outlines derived from LOLA data (source and method must be stated; no hand-drawn polygons), exported as GeoJSON/JSON in the same projected coordinates; draw as a toggleable overlay; optionally distance-to-PSR per site as a new field in a **new** JSON.
3. State resolution, data source, and date on the map.

## Done when
Map shows all sites correctly placed; click navigates; overlay toggles; page remains usable without the map (fallback to the cards).
