# M1 — Real terrain (LOLA DEMs -> horizons)
Read `AGENT.md` first. Status log: `docs/M1-STATUS.md`.

**Goal:** every site's horizon comes from a real LOLA DEM so the on-screen percentages are predictions. **People:** 2 (A: coordinates, frame, literature validation; B: coverage, IM-1/IM-2 crops, banner, final build). A third person is not needed.
**Owns:** `pipeline/dem/`, `pipeline/sites.json`, `build_data.py`, `horizon_dem.py`, `public/data/{sites,ephemeris}.json`. **Must not edit:** app pages. Only one person runs the final `build_data.py` and commits.

## Steps
1. DEMs in `pipeline/dem/<site-id>.tif` (5 m tiles for Site01/04/06/07/11; crops from `LDEM_80S_20MPP_ADJ.TIF` for im2-athena and `LDEM_75S_30MPP_ADJ.TIF` for im1-odysseus; see AGENT.md section 5 for URLs).
2. **Fix Shackleton rim coordinate** (A): current (-89.7668, 188.13) is the Site04 tile centre and sits on a ~30 deg wall (32 deg horizon). Published rim: ~89.78S, 204.27E (Mazarico 2011 point 4). Decide and document the chosen point with its source.
3. **Coverage** (B): tiles are ~+-8 km but `max_dist_m` is 15 km. Either pass `max_dist_m` = tile half-width, or label the limit on the Method page. Rays leaving the DEM must not silently shorten the horizon.
4. **Frame/longitude test** (A): locate craters in the 80S mosaic and compare to published lon (Shackleton 89.90S 0.2E, de Gerlache 88.70S 291.9E, Amundsen 86.28S 308.1E).
5. **Banner** (B): `src/App.jsx:13` uses `.some()`; either make all 7 real or make it site-aware (coordinate with the page owner).
6. Rebuild, sanity-check, run tests, commit data, update `docs/M1-STATUS.md`.

## Done when
"Demo terrain" banner is gone for >= 3 sites (target: all 7 or banner is site-aware), checks below pass.

## Checks (an agent can run these)
Use a venv with `pipeline/requirements.txt`. Run from the repo root.
| # | Check | Command / method | Expected |
|---|---|---|---|
| 1 | Files present | `ls pipeline/dem` | `.tif` for each real site id in `pipeline/sites.json` |
| 2 | DEM opens, CRS, nodata | `python -I -c "import rasterio;d=rasterio.open('pipeline/dem/connecting-ridge.tif');print(d.crs,d.shape,d.res)"` | CRS present; 5 m (or 20/30 m) pixels |
| 3 | Units/range | read band with `masked=True`, print min/max | metres; roughly -5000..+7000 near the pole; not km, not NaN-only |
| 4 | Site inside DEM | `horizon_profile(...)` must not raise "site lies outside the DEM" | no exception |
| 5 | Horizon plausible | after build: for each site `max(horizon)` | a few degrees (rule of thumb < ~8 deg); **flag** any site with a flat 0 line or any max > 15 deg and investigate (Shackleton rim at its current coordinate is the known offender) |
| 6 | No wall artefacts | adjacent-azimuth jump `max(abs(diff(horizon)))` | no jump > ~10 deg unless a mapped cliff |
| 7 | Coverage | per azimuth, distance where ray leaves the DEM | >= configured `max_dist_m`, else documented limit |
| 8 | Coordinates vs source | compare `sites.json` lat/lon to PGDA README numbering / Mazarico 2011 / LROC | each documented in `sites.json` `_comment` or note |
| 9 | Literature illumination | compute sunlit % over a lunar year per site with the app's `windowStats` logic and compare: Connecting Ridge ~89.0 % (max shadow 141 h), Shackleton rim ~86.7 %, de Gerlache rim ~85.6 %, Peak near Shackleton ~85.5 % (Mazarico 2011, 20 m-class data, other height/time) | within roughly +-10 points; larger gaps must be explained, not hidden |
| 10 | Terrain labels | `public/data/sites.json` `terrain` | `LOLA DEM, observer 2 m` for real sites, `synthetic-demo` otherwise |
| 11 | Banner | run app, open `#/` | banner absent when no site is synthetic (or site-aware) |
| 12 | Reproducible | run `build_data.py` twice | `ephemeris.json` byte-identical both times |
| 13 | Regression | `npm test` and `python pipeline/tests/test_geometry.py` | all pass |
| 14 | Repo hygiene | `git status` | no `.tif` staged; `.bak` files not committed |

Known risks: App Control DLL blocking on Windows (see AGENT.md); `jplephem==1.2` pin; Nobile DEM heights (~860-6800 m) use a different offset than the other tiles.
